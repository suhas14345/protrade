EPIC 4 — TRADE MANAGER (pro exits: MFE/MAE, time stops, trailing)
Prompt 4.1 — Create tradeManager.ts to manage open trades daily
Prompt to AI tool:

Implement tradeManager.ts scheduled daily after EOD bars update:

Query signals with status IN_TRADE and execution.status == FILLED.
For each, load bars from entryDateId to current dateId (bounded last 10–20).
Compute:

MFE = max favorable move since entry using highs/lows
MAE = max adverse move since entry using highs/lows
Convert both to R multiples using initial riskPerShare = abs(entry - stop).


Exit rules:

If price touches stop ? exit at stop (record exit)
If price touches target ? exit at target
If MFE >= +1R and then close returns to entry ? exit breakeven
If after 5 bars MFE < +0.5R ? time exit at close
If MFE >= +2R ? trail stop to entry +0.5R (BUY) / entry -0.5R (SELL)


Write a trades/{userId}/trades/{tradeId} doc and set signal.status = DONE.


Definition of done

Trades close automatically with pro rules.

Note on daily ambiguity

If both stop and target touched same day, record both and provide conservative/optimistic outcome flags.
